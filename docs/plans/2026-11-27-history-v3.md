## 1. Cell History root-cause fixes

| # | Fix | File |
|---|---|---|
| a | Order at rotation AND hourly while refused: expire > KEEP_DAYS -> gzip closed `.jsonl` (one per pass, `nice`, `gzip -c f > f.gz.tmp && mv && rm`) -> size cap oldest-first (never today) -> `df` -> floor. No whole-day latch: retry hourly. State to `/tmp/qmanager_cell_history_state` (`state=ok|low_space|...`, `free_kb=`, `archive_kb=`). | poller |
| b | `_QENG_PARSED` but no served cell -> write a `"NOSVC"` row with no carriers; CGI counts it as a service gap, never as signal. | poller, agg |
| c | Row v2 carries every `network.carrier_components[]` entry. | poller |
| d | Window end = wall clock; `recorder` block (state, stale_sec, free_kb, archive_kb, oldest_ts, l1_enabled). | CGI |
| e | Positional rows split by awk, per-closed-day reduced cache. | `history_agg.sh` |
| f | Delete unused `CELL_SERVED_PANELS`, `CELL_ROW_RE`; torn line rejected by column count / JSON shape. | CGI |
| g | UTC day file names kept (storage only). Maths in epoch. `device_utc_offset_min` in responses. | CGI |
| i | Deep tier: when a history row is due, run `AT+QCAINFO` + per-antenna read once (<= 1/min) so carriers aren't frozen. | poller |

Defaults: `KEEP_DAYS=30`, directory cap 3072 KB (sum of `ls -ln` sizes),
floor 4096 KB — all overridable by UCI `quecmanager.history.{cell_keep_days,cell_cap_kb,cell_floor_kb}`.

## 2. Archive row schema v2

One JSON ARRAY per line (valid JSON, ~half a keyed row, awk-splittable).
v1 lines start `{"ts"`, v2 lines start `[2,`. `null` when unknown, never 0.

Head columns (1-based):

| # | field | unit / values |
|---|---|---|
| 1 | v | `2` |
| 2 | ts | epoch s |
| 3 | rat | `"LTE"`, `"NSA"`, `"SA"`, `"NOSVC"` |
| 4 | nr_avail | `0`, `1`, `null` |
| 5 | tier | `"a"`, `"i"`, `"d"` |
| 6 | lte_cell_id | int |
| 7 | lte_tac | int |
| 8 | nr_cell_id | int |
| 9 | nr_tac | int |
| 10 | lte_scc_count | int |
| 11 | nr_scc_count | int |
| 12 | total_bw_mhz | int |
| 13 | lte_cqi | int (from AT+QENG, free) |
| 14 | tx_power | dBm, 1 decimal (QENG raw / 10) |
| 15 | lte_mcs | burst mean |
| 16 | lte_ri | burst max |
| 17 | lte_ul_mcs | last |
| 18 | nr_mcs | burst mean |
| 19 | nr_ri | burst max |
| 20 | nr_cqi | burst mean |
| 21 | nr_ul_mcs | last |
| 22 | prb_mean | PRBs, burst mean of `*_csi_ext` f7 |
| 23 | prb_max | PRBs |
| 24 | prb_n | snapshots in burst |
| 25 | n_rb | carrier PRB count from bw x SCS table |
| 26 | dl_bps | bits/s, burst mean of `up/down` |
| 27 | ul_bps | bits/s |
| 28 | temp_c | int |
| 29 | cpu_pct | int |
| 30 | mem_pct | int |
| 31-34 | lte_ant_rsrp[0..3] | dBm |
| 35-38 | nr_ant_rsrp[0..3] | dBm |

Then one trailing array per carrier, PCC first:
`["P"|"S","L"|"N",band,arfcn,bw_mhz,pci,rsrp,rsrq,sinr,rssi]`

Example:
`[2,1795000000,"NSA",1,"a",48466199,55383,null,null,0,1,60,11,12.0,5,1,19,27,2,15,25,88,133,6,133,177000000,350000,45,30,40,-85,-125,-118,-74,-58,-94,-91,-60,["P","L",1,250,10,104,-75,-10,6,-47],["S","N",41,509070,50,47,-58,-10,30,null]]`

- PRB share is derived at read time: `prb_mean / n_rb`. N_RB table (TS 38.101-1
  5.3.2-1, FR1 30 kHz): 5:11 10:24 15:38 20:51 25:65 30:78 40:106 50:133 60:162
  70:189 80:217 90:245 100:273. LTE (15 kHz): 1.4:6 3:15 5:25 10:50 15:75 20:100.
- Ping is NOT in the row (own archive, joined by ts).
- Size estimate ~290 B/row @3 carriers, ~420 KB/day raw, ~50-70 KB gzipped
  (to be measured; acceptance check).
- v1 compat: reducer detects the first byte and maps v1 keys (ts, rat,
  lte_pci, lte_band, lte_earfcn, lte_bw, lte_cell_id, lte_tac, nr_pci, nr_band,
  nr_arfcn, nr_avail, rsrp, rsrq, sinr) to the same reduced columns with a
  synthetic PCC (+ NR SCC when nr_pci set). Nothing rewritten; v1 ages out.

## 3. New AT reads (only when `quecmanager.history.l1_stats=1`)

- NEVER read `*_mimo_layers` from the poller (firmware hazard in wrong RAT,
  `ondemand_radio.sh:303`). MIMO rank = RI from `*_csi_ext`.
- By current RAT, ONE compound exchange through the poller's qcmd path
  (honours the QSCAN long-command yield):
  - LTE: `AT+QNWCFG="lte_csi_ext";+QNWCFG="lte_ulMCS";+QNWCFG="up/down"`
  - NSA: `lte_csi_ext`, `nr5g_csi_ext`, `nr5g_ulMCS`, `up/down`
  - SA:  `nr5g_csi_ext`, `nr5g_ulMCS`, `up/down`
- Reply formats (measured): `+QNWCFG: "nr5g_csi_ext",1,<mcs>,<ri>,<cqi>,<pmi>,<f6>,<prb>,<f8>`,
  `+QNWCFG: "lte_csi_ext",1,<mcs>,<ri>,<cqi>,<pmi>,<?>,<?>,<?>`,
  `+QNWCFG: "nr5g_ulMCS",1,<mcs>,<?>`, `+QNWCFG: "lte_ulMCS",1,<mcs>,<?>`,
  `+QNWCFG: "up/down",<ul_bits_s>,<dl_bits_s>,<interval>` (BITS/s on this fw).
  First field `0` on a csi_ext = reporting off (factory reset) -> record null.
- Gates (all): AT-due cycle with `_QENG_PARSED=1`; network type and PCC PCI
  unchanged since previous cycle; no scan / SIM switch in progress; busy reply
  abandons the minute.
- Sampling (accumulate sum/max/n, reset when the row is written):
  active: 1 exchange per 6 s while netdev DL > 1 Mbit/s, else 1/min;
  idle: 2 back-to-back per 15 s touch, same traffic gate; deep: 3 back-to-back
  in the row-due cycle.
- Budget: ~120-160 ms per exchange -> <= ~1.6 s/min worst case.
- LTE CQI (QENG field 16) and tx_power (field 17, 0.1 dBm) are free from the
  existing QENG read — confirm field positions against
  `tools/poller-parity/fixtures` for both LTE layouts in `parse_at.sh`.

## 4. CGI contract

- `fetch_signal_history.sh?view=cells&range=` keeps its name; logic moves to new
  `scripts/usr/lib/qmanager/history_agg.sh`. Response = `CellHistorySuccess`
  (frozen type), `cells.band_series` filled from `carriers[].rsrp` keyed
  `"B<n>"`/`"N<n>"`.
- Closed-day reduced cache `/tmp/qmanager_hist_cache/<day>.r<bucket>.tsv`
  built once (mkdir lock, atomic mv), rebuilt lazily after reboot; dir capped
  2 MB, evict oldest.
- Response cache `/tmp/qmanager_hist_cache/resp_<range>.json` reused while
  < 55 s old and newer than today's file (`date -r`). Hook polls 60 s.
- Buckets: 1h/3h 60 s, 6h 120 s, 12h/24h 300 s, 7d 1800 s, 30d 7200 s.
- Targets: 24h < 1 s; 30d < 3 s warm.
- Restarts from `/usrdata/qmanager/boot_log.jsonl` inside the window.
- Congestion `saturated`: bucket mean dl_bps >= 20 Mbit/s AND prb_n >= 3.
- `fetch_ping_history.sh` with NO query: byte-identical to today.
  `?range=1h|6h|24h|7d` -> `PingHistoryRanged` from the ping archive (+ the
  current partial minute from the tmpfs ring for freshness). Buckets: 1h 60 s,
  6h 60 s, 24h 300 s, 7d 1800 s.

## 7. Router-wide items in this release

- Antenna health verdict: per-port median RSRP vs the band's best port over the
  window; >= 20 dB down -> warning, >= 30 dB -> destructive ("RX 2 and RX 3 are
  far weaker than the others"). On the `antennas` panel and a dashboard status
  rail chip linking to /cellular/antenna-statistics. Live verdict uses
  `signal_per_antenna` from modem status.
- Restart history: the per-minute ping row is the heartbeat. At boot, once the
  clock is sane (epoch > 2024-01-01), the poller appends
  `{"boot_ts":..,"last_alive_ts":..,"down_sec":..,"cause":".."}` to
  `/usrdata/qmanager/boot_log.jsonl` (cap 60 lines). `boot_ts = now - uptime`;
  `last_alive_ts` = ts of last ping-minute row before boot_ts. gap <= 180 s ->
  `restart`; > 180 s -> `power_loss`; none -> `unknown`; a planned reboot marker
  in `/etc/qmanager/crash.log` near boot (`|reboot|planned` or similar —
  check how the poller/crash logic writes it) -> `planned`.
- Clock/timezone banner (no silent change).
- Poller pin (known-issues 15): `use-modem-status.ts` and
  `use-latency-history.ts` pause on `visibilitychange` (pattern from
  `use-cell-history.ts`).
