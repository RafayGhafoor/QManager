# 🚀 QManager BETA v0.1.32 (Draft)

v0.1.32 is in progress, headlined by a much faster connection to the modem: every command now answers in about 10 ms instead of about 1 s, which makes every page and background service more responsive. It also brings redesigned sign-in and landing pages, cleaner Network Events, and a polish and correctness pass throughout. Notes below are provisional and will be rewritten before release.

## ✨ New Features

- **SIM Profiles and Connection Scenarios share one page.** **Cellular → Custom SIM Profiles** now shows what is in force right now, today's schedule as a 24-hour timeline, and your saved profiles next to your scenarios, so you can see and change everything in one place. Creating or editing a profile opens in a dialog, and you can add a scenario from the same page.
- **Modem commands are about 100× faster.** Each command to the modem now takes about 10 ms instead of about 1 s. Two changes add up: commands release the modem the moment they finish, and QManager now keeps one connection to the modem open instead of starting several helper programs for every command (a further 5× on its own). Pages and background services no longer queue behind each other, a modem that stops answering can no longer leave everything waiting for minutes, and a late answer can no longer show up in the wrong place. It also picks itself back up when the modem restarts, never sends the same command twice, and answers at once while a cell scan is running instead of waiting for the scan to finish.
- **New System Health Check.** **System Settings → System Health Check** tests every part of QManager on your modem in about ten seconds, from the modem connection and background services to the firewall and your settings files, and lists anything that failed or needs attention first. It changes nothing on the device, and you can download a support bundle with your IMEI, passwords, phone numbers and email addresses removed.
- **Run QManager on a port of your choice.** QManager still uses ports 80 and 443 by default, but you can now move it (and LuCI with it) to other ports from **System Settings → Web Port**, from the new optional step in first-time setup, or when the installer asks during an SSH install. Over SSH, `qmanager_web_port set 8080 8443` does the same, and `qmanager_web_port reset` goes back to 80 and 443. If the web server can't start on the new ports, the old ones come back on their own.
- **New Host AT Ports setting.** **System Settings → Host AT Ports** stops a computer connected over USB or PCIe from sending AT commands to the modem. It's on by default, matching stock firmware.
- **Text messages are now conversations.** **Cellular → SMS** is redesigned as a two-pane messenger: your contacts on the left, the conversation on the right, with the messages you sent shown alongside the ones you received. Reply from the box under the thread, search and filter by unread, and long-press or right-click a message to copy it (or the one-time code in it), forward it, mark it unread, see its details or delete it. Sends appear instantly and can be retried if they fail, a conversation can be opened straight from a link, and the list refreshes on its own.
- **New SMS settings.** The **⋮** menu on the SMS page opens SMS settings, where you can change your provider number (the message service center your carrier uses to send texts) and choose where new messages are saved: on the modem (room for 255, the default) or on the SIM so they travel with it. It shows how full each one is and warns before one fills up. Messages you already have stay where they are.
- **Sender names and logos.** Texts from banks, carriers and services now show the sender's name and, for well-known brands, their logo instead of a bare number. Logos are only ever looked up for a short list of known brands and are never matched loosely, so a look-alike sender name does not get one; with no internet you see the sender's initials. Messages with links carry a reminder that sender names can be faked.
- **Update Tailscale from the Tailscale page.** When a newer version is available, a small Update available button appears next to the version in This device. Tailscale downloads the new version, checks it, swaps it in and reconnects in a few seconds without asking you to sign in again. If the new version doesn't start properly, the previous one is restored automatically and you're told so. The update progress is shown as it runs.
- **Tailscale now installs the official build.** Install fetches Tailscale's own build straight from Tailscale and checks it before using it, so the version shown is the real one and a download that can't be verified is refused. There is no build to choose any more.
- **Suggested APNs for your SIM.** The APN field in **Cellular → APN Settings** now has a list of the APNs your carrier uses for mobile data, picked from your SIM, like the APN screen on a phone. Choose one to fill the field, or type any APN as before.
- **New Prometheus metrics endpoint.** **Monitoring → Prometheus** lets a Prometheus server collect your modem's signal, carrier aggregation, connection quality and health readings. It is off by default and protected by a private token that you can show, copy or regenerate, and the page gives you a ready-to-paste scrape config. A Scrape freshness setting decides whether scraping keeps the modem reading at a faster pace (Adaptive leaves it alone, Balanced stops it dropping to its slowest pace, Real-time reads it every 2 seconds like an open dashboard). Identifiers such as IMEI, IMSI, ICCID, phone number and IP addresses are never included, and the token is left out of configuration backups.

## ✅ Improvements

- **APN Settings opens on modems without QMAP support.** On modems whose firmware does not understand the QMAP command, the APN page failed to load. QManager now works out which connection carries your data from the addresses the modem and the router report, so the page loads and marks the right connection. The same fix keeps the WAN address on the dashboard and Load from SIM correct. APN names are now checked (letters, numbers, dots, hyphens and underscores), saving over an IMS or emergency connection is refused unless you confirmed it, a case-only APN difference no longer restarts the connection at boot, and the "Not live" badge no longer flips while you type.

- **Saving the active profile updates its schedule straight away.** Changing the schedule on the profile in use now takes effect immediately instead of waiting for the next activation.
- **Network edits to the active profile say when they apply.** Changes to the APN, IMEI, TTL or hop limit are marked "Applies on next activation", with a one-click Reapply when you want the connection to restart. Nothing reconnects behind your back.
- **Old Connection Scenarios links keep working.** The separate Connection Scenarios page now takes you to the combined page.
- **Data Used and Storage are back on the dashboard.** The Device & Speed card shows how much you have downloaded and uploaded since your last reset, kept across reboots and connection drops, with a reset button beside it, and how full the modem's storage is.
- **First-time setup no longer skips settings that didn't apply.** Choosing "APN only" during setup never actually saved the APN, and a network mode or band lock the modem rejected was silently dropped while setup moved on. Each of these now saves for real, and if the modem refuses one, setup stays on that step and tells you why, so you can try again or skip it. The setup wizard also has a refreshed look in the new design, with the QManager mark on the welcome screen.

- **Activating a profile made for another SIM now asks first.** Custom SIM Profiles marks profiles bound to a different SIM, and activating one asks you to confirm applying it to the SIM in the modem. The note on an active profile like this now says what really happened: it is in use on this SIM and turns off at the next restart or SIM change (it used to say the device kept its old settings).
- **Redesigned Tower Locking page.** Tower Locking now opens by showing whether the modem is on the cell you locked, with every cell it is using as a tile that shows its state at a glance. Lock a cell, add it to a lock or remove it with one tap on its tile, and locked cells the modem is using are marked. Keep after reboot is now chosen per radio (4G and 5G) inside each lock card, the signal failover threshold is a slider that saves as you let go, and the lock schedule sits beside them. The 4G and 5G cards are simpler, and Frequency Locking follows the same layout without an apply bar. If the modem doesn't report its lock state, the page now says so instead of showing "Unlocked", and Remove lock stays available. Changing the locked cell is no longer blocked while signal failover is watching.
- **Cleaner IMEI Settings.** The IMEI card no longer repeats the current number; a badge shows whether what you typed matches the IMEI on the modem. The IMEI tools show whether a number passes the check-digit test as text ("Luhn valid" or "Luhn invalid") plus a coloured outline on the check digit, and Reset is now a single icon beside Save.
- **Clearer Connection Scenarios.** The running scenario shows a pulsing green dot, the one you have selected is a quiet outline, the tiles have room for their pulse, and the configuration card folds its details away until you open them. Adding a scenario is a button that expands on hover.
- **Neater Cellular pages.** The action buttons on the Cellular overview shrink to icons that expand with their label when you hover, Copy diagnostics sits next to the band reference, and the Cellular Settings live view and Refresh button match the Band Locking style. Band Locking's select all and deselect all are now icon buttons at the left edge that reveal their label on hover.
- **A friendlier 404 page.** A page that doesn't exist now shows a small pixel campfire with a button back to the dashboard.
- **Redesigned Cellular Settings page.** Cellular → Settings now opens with a live view of your network, SIM, carrier aggregation and data path, shows the rate limits your carrier grants, and groups the settings into two cards where every option says what changing it does to your connection. Changes are saved together from one place, with each step shown while the modem applies them, and anything that didn't apply stays marked so you can retry just that. It also adds SIM hot-swap detection and shows whether your second SIM slot holds a card.
- **The background poller uses far less CPU, and the dashboard refreshes every 2 seconds as intended.** The service that reads signal and connection data now takes a fraction of the processing power it did before (about 5% of one core instead of about 40% while the dashboard is open), and a busy or stuck modem request can no longer freeze the readings for long.
- **No more false "Modem became unreachable" events while the modem is busy.** When another task was using the modem for a few seconds, Network Events could log the modem as unreachable and then restored, and the dashboard briefly showed it as degraded. QManager now waits it out and keeps showing the last readings, and only reports the modem unreachable when it really stops answering. The AT Terminal also refuses text that isn't an AT command (such as a typo without the AT in front) with a clear message, instead of freezing every other modem request for 20 seconds.
- **Settings survive a sudden power loss.** Saving your password, SIM profiles, TTL, DNS, email alerts, Tailscale and language packs now replaces the old file only once the new one is safely on flash, and every reboot flushes pending writes first, so a power cut or freeze can no longer leave a setting empty. A password change that cannot be saved now says so instead of reporting success.
- **Redesigned dashboard.** The dashboard now opens with a heading and two status chips (radio on or off, and whether the internet answers, with a pulsing dot while it does). A new Carrier Aggregation card draws each carrier as a share of your total bandwidth with its band, signal and role, the 4G and 5G cards show each reading on a colour-graded bar, Recent Activities marks what is still unresolved, and the speed test shows each step as it runs. The speed test tile now leads with a play button and spreads its three figures out, the two cell distance readings share one row, and their explanations open from a small info icon, so they work on a phone too.
- **Redesigned System Settings, Tailscale, Logs, Languages, Software Update, About, Support and AT Terminal pages.** Each opens with a status strip that answers the main question at a glance (is Tailscale connected, is an update waiting, how many errors are in the log), and its settings sit in clearly titled cards that save from one place and confirm with one message. Software Update can now install any listed version and shows each step of an install, Logs can be filtered by severity and copied, and the AT Terminal groups its ready-made commands by topic.
- **Tailscale can now turn on Tailscale SSH and shows a live install log.** A new Tailscale SSH setting lets members of your tailnet open a shell on the modem, as your Tailscale access rules allow; it asks you to confirm before turning on. While Tailscale installs, the page now shows the installer's output as it runs.
- **Devices on your tailnet can now reliably reach the modem and your network.** Pinging the modem, opening QManager or connecting over SSH through Tailscale used to fail on some setups, even with the old Force Tailscale Fixes setting on, because the fix did not last. It is now applied automatically when Tailscale connects and every time the modem starts, and it stays in place.
- **The Tailscale network fixes setting moved to the Tailscale page.** Force Tailscale Fixes is gone from System Settings. A Network fixes row on the Tailscale page replaces it, on by default, and you rarely need to touch it.
- **Older community Tailscale installs are now flagged.** If Tailscale was installed from the older community package, the Tailscale page says so with a notice and a Community build label. Uninstall it and install again to get the official build with updates. It keeps working in the meantime.
- **Tailscale shows its real version.** The version shown after installing no longer reads "latest" and now sits in This device, and the page header is simpler: the Refresh button now sits on the Connection card.
- **Installs and updates now survive a power cut.** QManager now makes sure each new file is fully saved to the modem's storage before it replaces the old one and before any service restarts or the modem reboots. A crash or power cut mid-install can no longer leave empty program files behind that stop QManager working until you reinstall.
- **Software Update now warns when an earlier install didn't finish.** If an update was cut off part-way (for example by a power cut), the page says so and offers to reinstall that version in one step, instead of looking like a normal, up-to-date device.
- **Redesigned Configuration Backup and Adaptive Polling pages.** Backups now also save your connection quality thresholds and latency monitor sites, and the section list is split into connection and monitoring settings. Restoring walks you through choosing the file, entering its passphrase and reviewing what will be replaced, then shows each section's progress step by step and tells you plainly which sections failed or were skipped. Adaptive Polling now shows the current polling tier as a clear chip, saves from the bottom of its card, and is fully translated.
- **Redesigned Traffic Engine, Custom DNS and NetBird pages, and a cleaner LAN Address card.** Traffic Engine opens with what the engine is doing right now, and each mode saves from the bottom of its own card. Custom DNS uses the full page width, with one-tap on and off and your servers listed at a glance. NetBird shows your connection, this device and its peers in separate cards that fit a phone. Every save, install and removal now confirms with one message, and a failure says why.
- **Redesigned Ethernet Status page.** A link strip shows whether a cable is connected, the negotiated speed (and the most the port supports), duplex, and whether the speed is negotiated or forced. A speed limit is now applied from the bottom of its card instead of the moment you pick it, so a stray click can't drop your connection, and the page now says when the modem stops answering instead of showing frozen readings.
- **Redesigned Band Locking, APN, SMS, Custom SIM Profiles and Connection Scenarios pages.** Band Locking opens with a status card showing the carriers on air, how locked each band group is and the failover safety net, and each band is now a large tap target that shows both what you picked and what the modem is using, so you can see a pending change before you apply it. SMS Forwarding now puts its on/off and destination card first, with a status panel beside it that shows whether messages are reaching your number, how a forwarded message will look, and any that failed. APN Settings puts the APN and carrier profile cards side by side, shows the APN the network is actually using right above your saved one, and lists every carrier profile at a glance. Custom SIM Profiles shows your saved profiles or the editor one at a time, points to a missing field instead of a pop-up, and confirms each activation. Connection Scenarios drops the coloured gradients for clear icons and labels, with one dialog to add or edit a scenario, and each custom scenario can now have its own icon. Every failed change on these pages says why it failed.
- **Configuration Backup now works over a plain http:// address.** Creating or opening a backup used to fail with "Couldn't create the backup." unless you reached QManager over HTTPS, and restoring reported a wrong passphrase even when it was right. Backups now encrypt and decrypt on any connection, and files made either way open either way.
- **Reboot reminders now follow you around the app.** When a change needs a reboot to finish (a restored backup, an IMEI or carrier profile change, Hardware Offload, removing NetBird) and you choose Later, a reminder with a Reboot now button stays at the top of every page until you reboot, instead of only on the page where you made the change.
- **One place to save on every settings card.** Cellular, APN, IMEI, network priority, band locking, SMS forwarding, System Settings, TTL, MTU, custom DNS and LAN settings now save from the bottom of their card, which shows when you have unsaved changes and has a Discard button. Every save confirms with one message instead of a label that fades away.
- **Redesigned landing page.** The page you see before signing in now leads with whether the internet is up and how warm the modem is, then shows each carrier's signal strength on a colour-coded bar with a switch between signal power and signal quality, then your carrier, network type and total bandwidth. It also tells you plainly when the readings are stale or the modem is offline.
- **Redesigned Network Events page.** A new Right now card shows what is still going wrong and what keeps repeating, an Activity chart shows when problems, recoveries and routine changes happened, and runs of the same event are grouped into one row you can open. Band and cell IDs appear as tags, and the list can be paused while you read it.
- **Redesigned IP Passthrough page.** A Last applied strip at the top shows the saved mode, target device, NAT, USB connection, DNS proxy and whether the modem still answers at its LAN gateway. Below it, every setting is a one-tap choice, the lockout warning on Mode turns red while you are about to change it, and a dot marks each unsaved change. You can still pick the target from the devices on your LAN or type its MAC, and an apply that fails now tells you which step went wrong.
- **Redesigned Connection Quality page, plus a Connection Quality card on the dashboard.** The page is now two compact cards: Probe Targets (how often the modem checks the internet, the IPv4 target and the IPv6 fallback, with a chip showing which one is answering) and Quality Thresholds (presets or your own limit, beside the live reading). Saves now confirm, and a failed save says why. On the dashboard, the Live Latency chart is replaced by a card showing internet and DNS response times, 30 minutes of reachability and jitter, typical and worst latency, and packet loss. The speed test moved to the renamed Device & Speed card, with a Run test button and your last download, upload and ping; a test running anywhere, even in another tab, shows its live step, speed and progress there.
- **The landing page now shows the temperature in your unit.** If you chose Fahrenheit, the page you see before signing in now uses it too, instead of always showing Celsius.
- **Redesigned sign-in screen.** The sign-in card now leads with your modem's name, has a cleaner layout in light and dark mode, keeps the language and theme switchers in the corner, and shows a clear message if the modem can't be reached. The "session expired" notice now sits right under the Sign in button instead of above the form.
- **Status chips and info tips are easier to read.** Status chips now have their own icon for each state, so two different states no longer look alike: a service that isn't installed, a NetBird connection error, Software Update while it loads, a partial antenna-alignment reading and an alert that wasn't sent. The "Experimental" label on Frequency Locking is now a blue information chip. Explanations that used to appear only on hover (the Internet chip on the dashboard, the SCS guess on the 5G SA tower card, the SCS "Derived" marker on Cellular, and a provider's network codes in the Cell Scanner) now open from an info icon that also works when you tap on a phone.
- **Failed sign-ins now show how many attempts remain.** If you're locked out, a countdown shows when you can try again, and it keeps counting if you refresh the page.
- **Repeated failed sign-ins now lock out progressively.** After five wrong passwords the form locks for 30 seconds, and each further failure after a lock expires waits longer, up to 15 minutes. A correct password or an hour without a failed attempt starts you fresh.
- **Sign-in errors now appear in your language.** Incorrect-password and lockout messages are translated instead of always showing in English.
- **The Live Traffic monitor has been removed.** Its readings were inaccurate and it kept a network port open on your LAN without a password. The System Settings page and the dashboard row are gone, and upgrading cleans everything up automatically, including the websocat package and port 8838.
- **More reliable modem readings and background services.** IP Passthrough settings and timing-advance readings now always come from the modem's answer, never from the echoed command, so they can no longer show a stale or default value. Background services now fall back safely instead of quitting silently if one of their helper files is missing.
- **A modem that doesn't answer is no longer reported as a success.** Cellular settings, IMEI, MBN, IP Passthrough, network priority, FPLMN, custom DNS, frequency lock status and SIM profiles now say the modem didn't answer instead of showing defaults or confirming a change that never happened. Clearing tracked SIMs no longer removes the inserted SIM when the modem is busy. Low power mode now waits for the correct time after a restart before deciding to turn the radio off. Scheduled connection scenarios no longer apply an old scenario after the clock jumps. The watchdog's primary SIM check now finishes correctly when maintenance interrupts it. The Logs component filter lists only real components.
- **One outage, one lost and one restored entry.** Network Events no longer logs the same outage twice, and an outage the watchdog fixes on its own is now recorded and alerted like any other instead of slipping through. Slow-connection and packet-loss entries also wait until a problem has actually cleared before announcing recovery, and stay quiet right after the connection returns.
- **Carrier aggregation no longer floods Network Events.** A carrier that blinks out for a moment is ignored. A real change is announced once it holds, and a carrier that keeps flapping shows a single "churn detected" warning, followed by a "settled" entry once it calms down. Added-and-removed band lists also read correctly now.
- **SMS now goes through the same fast modem connection as everything else.** The SMS inbox, sending, SMS alerts and SMS forwarding no longer start a separate helper program that competes with the rest of QManager for the modem, so they no longer stall behind other pages or report the modem as busy for no reason. Delete All now clears every message, including ones stored past the 50th slot, and a modem that is busy now shows as busy instead of as an empty inbox. Messages, read state and forwarding history carry over unchanged. Two long messages from the same sender that happened to share an internal reference number are no longer stitched into one garbled message. The old SMS helper is no longer included in the package, which makes it smaller.
- **SMS and email alerts share one wait time.** The number of minutes an outage must last before you are alerted is now a single setting used by both channels, so they can no longer disagree. Existing wait times carry over.
- **Safer handling of temporary files.** Updates, language packs, the traffic engine, Tailscale and speed tests now download and unpack into a private folder only QManager can write to, and settings it keeps in temporary storage are written in one step and checked before use. Another program on the modem can no longer swap in its own files or redirect QManager's writes. QManager also switches on the kernel's own protection for shared temporary folders, and the installers for the traffic engine, Tailscale, NetBird and email alerts, plus SMS forwarding, can no longer be blocked by a fake "already running" file.
- **Updates are always checked before they install.** A downloaded update, a direct install or a rollback is now checked against the release's published checksum, and refused with a clear message if it cannot be checked or doesn't match, instead of installing anyway.
- **Fixed a tower-lock re-apply that could stop the service that started it.** Re-applying a custom MTU twice in a row after a tower lock change now only replaces the earlier re-apply. SMS forwarding also now stops cleanly when told to, so a second copy can't start beside it.
- **Scheduled actions no longer misfire after a reboot.** The modem's clock starts out wrong at every boot and is corrected a little later. A scheduled reboot could fire again as soon as the clock was corrected, which risked a reboot loop. Scheduled reboots, low power mode, scheduled tower locks, connection scenario schedules and automatic updates now check that the modem has been up for a few minutes and that it really is the scheduled time before they act. Saving a scheduled reboot, low power or tower lock schedule again no longer piles up duplicate entries, and a scheduled reboot can only fire once in the same minute.
- **Safer SIM failover in the watchdog.** A backup SIM that is still starting up is no longer mistaken for an empty slot. A SIM switch interrupted by a cell scan or a profile change is switched back instead of being left half-done. The periodic check of the primary SIM is no longer thrown off when the clock is corrected after a reboot.
- **Tower lock failover only reports success when both locks are cleared.** If one of the two locks could not be removed, failover now says so, retries, and keeps watching, instead of reporting the locks as cleared. Scheduled tower locks no longer claim to be active when the modem never received them.
- **Redesigned Watchdog page.** A status card shows what the watchdog is doing with a strip of recent probes, the recovery ladder and the detection settings sit side by side, and the newest recovery activity sits below. Each card now has its own Save, so saving one card never touches the other, and the page asks before it lets the watchdog reboot the modem. The probe interval set here now really takes effect, and saving the ladder can no longer clear your backup SIM slot.
- **Alert failures now say what went wrong.** A failed save, test or uninstall on the Alerts page now shows the actual reason in your language instead of a generic message. The Activity list names each alert (connection lost, connection restored, modem rebooted, test message) in your language too.
- **Reboot alerts are recorded with the right time and cause.** If the modem's clock has not been set yet when it starts up, the reboot is now recorded once the clock is correct, instead of being logged in 1970 or mislabelled as unexpected. Email alerts also give up on a dead connection after 30 seconds instead of stalling.
- **"Degraded" now follows your packet-loss threshold.** The connection status turns to degraded at the packet-loss level you chose in Connection Quality, instead of a fixed 10%.
- **Redesigned Latency Monitor, with a new Sites card.** **Monitoring → Latency Monitor** now shows the last five minutes of probes with a bar per probe, a cleaner one-line history over 1 h, 6 h or 24 h, and every colour graded against the limits you set in Connection Quality. The new Sites card shows how fast Google, YouTube, TikTok and other sites answer over the cellular link, live or averaged over an hour, a day or a week, and you can add, remove or pause sites from Manage.
- **Redesigned Cell Scanner, Neighboring Cells and Frequency Calculator.** A sweep or neighbour read now opens with a summary: the total, then each carrier (yours first and tagged) with its bands and best signal. The table has a filter, Download CSV and column picker in one row, sorts strongest signal first, and puts unmeasured cells last. Sweeps show an estimated progress bar. Lock to this cell is disabled, with the reason shown, for cells that aren't on your SIM's network. The Frequency Calculator puts the answer beside the input, shows each possible band's downlink and uplink side by side, and lets you re-run any history entry with one click. The uplink EARFCN is now correct for bands 30, 66 and 71.
- **A scan that stops answering now says so.** If the modem stops responding mid-scan, or the scan ends without a result, the page tells you instead of spinning forever. Switching language during a scan no longer stops the page from following it.
- **5G bands are now labeled correctly in the Cell Scanner.** NR5G cells show an `N` prefix (`N41`, `N71`) instead of the LTE-style `B` prefix. LTE cells still use `B`.
- **5G channel bandwidth is now shown in MHz, not raw resource blocks.** The Cell Scanner's BW column converts each NR carrier's resource-block count to its true channel bandwidth using the subcarrier spacing — e.g. an n41 carrier now reads 90 MHz instead of 245 MHz. If the modem doesn't report a spacing for a cell, the raw block count is shown labeled "PRB" rather than a misleading MHz figure.
- **Locking a scanned 5G cell now uses the correct subcarrier spacing.** When the scan didn't report a spacing for a cell, the lock previously assumed 30 kHz — wrong for FDD bands like n71 and n25 (15 kHz). It now infers the right spacing from the band instead of mis-locking.

## 📥 Installation

### Fresh Install

```sh
curl -fsSL -o /tmp/qmanager-installer.sh https://raw.githubusercontent.com/dr-dolomite/QManager/development-home/qmanager-installer.sh && sh /tmp/qmanager-installer.sh
```

### Upgrading from v0.1.31

**System Settings → Software Update.** No migration steps needed.
